## About

SinterDB is an open-source organization building a modern, developer-friendly database ecosystem.

Our projects span the core database, storage and protocol infrastructure, developer tooling, web experiences, and higher-level libraries designed to make working with SinterDB simple and flexible.

> [!NOTE]
> SinterDB is still in early development. APIs, behavior, and architecture may change as the ecosystem evolves.

## Projects

- **[SinterDB](https://github.com/SinterDB/sinterdb)** — The core database, storage engine, protocol, drivers, and supporting packages.
